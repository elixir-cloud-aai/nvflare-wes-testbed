# Test set

One minimal job and tiny, made-up data.

| What | Where | Source | Licence |
|---|---|---|---|
| Data of two sites, and a holdout set: 40 rows each, two features and a label | `data/` | Generated by `generate.py`, from a seeded random number generator and a fixed linear rule. Describes nothing and nobody. | Apache-2.0, as this repository |
| Job: logistic regression with NumPy, federated averaging over 5 rounds | `job/logreg-fedavg/`, exported from `job_src/` | Written for this repository, following the `hello-numpy` example of [NVFlare](https://github.com/NVIDIA/NVFlare) | Apache-2.0 |
| Comparison with models trained at one site alone | `evaluate.py` | Written for this repository | Apache-2.0 |

**Public or synthetic data only, tiny, with its source and licence stated. No clinical data and no data from Trusted Research Environments, ever, not even as an example.**

The two sites see different parts of the feature space, so a model trained at one site alone generalizes badly. Expected on the holdout set: federated 0.975, site 1 alone 0.825, site 2 alone 0.875.

To regenerate the data and the job, which gives the same files:

```sh
docker compose --profile test build flare-image
docker run --rm -u "$(id -u):$(id -g)" -e HOME=/tmp -v "$PWD/testset:/testset" nvflare-testbed:local \
    sh -c 'cd /testset && python generate.py && cd job_src && python job.py --export-to /testset/job --rounds 5'
```
