# Glossary

| Term | Meaning |
|---|---|
| Admin API | NVFlare's API to submit and watch jobs, and to shut down a federation |
| FedAvg | Federated averaging: a server averages the weights of the models that clients trained locally |
| FL | Federated learning |
| FL client, FL server | The participants in NVFlare. Clients hold the data and train; the server coordinates and aggregates |
| Federation | One server and its clients, with a common root certificate |
| Hub | Here: the machine with the thin WES and the FL server |
| Job | NVFlare's unit of work: an app for the server and an app for the clients |
| Non-IID | Sites whose data differ in distribution |
| Provisioning | Making the startup kits of a federation |
| Run | WES's unit of work |
| Site | An institution taking part; here, a TES and a share of the data |
| Startup kit | Configuration, certificates and a private key of one participant |
| Task | TES's unit of work |
